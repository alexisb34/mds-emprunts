Fondations

Les valeurs de base de l’outil d’emprunt : couleurs, espacements, rayons, ombres, polices. Chaque ligne donne le nom du token, sa valeur et un aperçu.

Dans votre CSS, écrivez var(--brand-primary) plutôt que la valeur de la couleur écrite en dur : la valeur change à un seul endroit, et tout le reste suit. Le bouton « Copier » met var(--nom) dans le presse-papiers.

Cette page lit css/tokens.css au lieu de le recopier. Si un token change ou s’ajoute, elle change avec lui.

Cette page lit les tokens depuis la feuille de style, ce qu’un navigateur refuse sur un fichier local. Ouvrez le site depuis un serveur : npm run serve.
